# 🏠 Cabinet — личный кабинет покупателя

Каждый покупатель получает **личный кабинет** на [rezon-ai.ru](https://rezon-ai.ru).

## Что внутри

```
Твой кабинет
 ├── статус подписки и срок действия
 ├── license key для локального сервера
 ├── мастер привязки (3 шага)
 └── готовые MCP-конфиги для Claude, Cursor, DSH и других
```

## Вход

Ключ кабинета показывается один раз при активации кода покупки — сохрани его сразу.
Пошагово: [PAIRING.md](PAIRING.md).

## Апгрейд с Free на Pro без потерь

Память из self-hosted установки переносится в облако через экспорт/импорт NDJSON
(кнопка «⬇ export» в дашборде или `/api/export`).

## Безопасность

- Каждый кабинет изолирован: свой ключ, своя память.
- Ключ кабинета — полный доступ: не публикуй и не скринь.
