# 🎨 MaxGraph Design System v2 — «Neon Cosmos HUD»

Единый визуальный язык для лендинга, кабинета покупателя и кабинета администратора.
Синтез трёх референсов (см. `docs/assets/` и вложения сессии):

| Референс | Что берём |
|---|---|
| **A. MaxGraph hero** (светящаяся сфера-сеть над ноутбуком, титул с блумом) | Космос, звёздное поле, неоновая сфера-сеть из бизе-кривых, парящие стеклянные окна-карточки, глоу-типографика заголовков |
| **B. Advanced Cognitive Architecture** (голографический мозг + HUD-панели) | HUD-панели с уголками-кронштейнами, UPPERCASE-заголовки панелей с glow, третий акцент — янтарь, тепловые карты/спарклайны, кольцевые HUD-окружности на фоне |
| **C. KAR CIZ dashboard** (тёмный дашборд с мятным акцентом) | Дисциплина сетки панелей: сайдбар, KPI-карточки с дельтами, донат-чарты, скруглённые барчарты, чистые таблицы, приглушённый вторичный текст |

Принцип слияния: **космос и неон A + HUD-хром B вокруг контента + строгая сетка и чарт-культура C внутри панелей**. Не наоборот: снаружи — магия, внутри — точность.

## 1. Токены (CSS custom properties — единственный источник правды)

```css
:root{
  /* --- поверхности --- */
  --bg:        #04070F;   /* глубокий космос */
  --bg-2:      #070D1A;   /* приподнятый фон (сайдбар) */
  --panel:     rgba(13,20,36,.62);   /* стекло HUD-панели */
  --panel-2:   rgba(18,26,46,.78);   /* панель плотнее (таблицы, модалки) */
  --line:      rgba(124,155,255,.16);/* базовая рамка */
  --line-hi:   rgba(70,240,255,.45); /* рамка hover/active */

  /* --- текст --- */
  --text:      #EEF1FF;
  --dim:       #8890B5;   /* вторичный */
  --faint:     #5A6285;   /* подписи, дата-время */

  /* --- неоновые акценты --- */
  --cy:        #46F0FF;   /* cyan — первичный (связи, данные, ссылки) */
  --mg:        #FF5BD8;   /* magenta — вторичный (эмоции, выделение) */
  --vi:        #8A6BFF;   /* violet — мост cyan↔magenta, градиенты */
  --mi:        #38D39F;   /* mint — успех, рост, «оплачено» (из рефа C) */
  --am:        #FFC94D;   /* amber — предупреждения, пики, «триал» */
  --rd:        #FF6B8A;   /* red — ошибки, просрочено */

  /* --- glow --- */
  --glow-cy:   0 0 24px rgba(70,240,255,.35), 0 0 64px rgba(70,240,255,.12);
  --glow-mg:   0 0 24px rgba(255,91,216,.30), 0 0 64px rgba(255,91,216,.10);
  --glow-mi:   0 0 18px rgba(56,211,159,.30);

  /* --- форма --- */
  --r-lg: 18px;  --r-md: 14px;  --r-sm: 9px;
  --blur: blur(14px);

  /* --- типографика (offline-first: системный стек, НИКАКИХ внешних шрифтов) --- */
  --font-ui:   'Segoe UI', system-ui, -apple-system, sans-serif;
  --font-disp: 'Segoe UI', system-ui, sans-serif;          /* + weight 800, letter-spacing */
  --font-mono: 'Cascadia Code', Consolas, 'Courier New', monospace;

  /* --- движение --- */
  --ease: cubic-bezier(.22,1,.36,1);   /* выход «с пружинкой» */
  --t-fast: .16s; --t-med: .28s; --t-slow: .6s;
}
```

## 2. Фон страницы (обязателен на всех трёх страницах)

Слои снизу вверх (все `position:fixed; pointer-events:none`):
1. `--bg` + мягкая радиальная виньетка.
2. **Звёздное поле** — 2 слоя radial-gradient точек (1px/1.5px, белый/#CDD6FF), второй слой с `animation: tw 6s ease-in-out infinite alternate` (opacity .45→.85). Мерцание только opacity!
3. **Аврора**: 2–3 пятна `radial-gradient(circle, rgba(70,240,255,.07), transparent 60%)` и magenta — `filter:blur(90px)`, позиции ~20%/80%.
4. **HUD-кольца** (только лендинг и пустые состояния): 1–2 тонких `border:1px solid rgba(70,240,255,.06); border-radius:50%`, диаметр 90–130vw, центр за пределами экрана.

`@media (prefers-reduced-motion: reduce)` — отключить twinkle/pulse/shimmer полностью.

## 3. Типографика и «красивые надписи»

- **Дисплейный заголовок (герой)**: weight 800, `letter-spacing:-.02em`, размер `clamp(34px,6vw,64px)`, градиентный текст:
  ```css
  background:linear-gradient(115deg,#FFFFFF 20%,var(--cy) 55%,var(--mg) 90%);
  -webkit-background-clip:text; background-clip:text; color:transparent;
  filter:drop-shadow(0 0 22px rgba(70,240,255,.35)); /* блум как на рефе A */
  ```
- **Заголовок панели (HUD)**: `text-transform:uppercase; letter-spacing:.14em; font-size:12px; color:var(--cy); text-shadow:0 0 12px rgba(70,240,255,.5)` + маленькая метка-«чип» справа, если нужен статус.
- **KPI-цифра**: weight 800, `clamp(26px,3vw,38px)`, цвет `--text`, дельта-чип рядом (`+4%` mint, `−2%` red).
- Тело: 14–15px, `line-height:1.6`, `--dim` для вторичного. Моно — для ключей, кодов, токенов.

### Фирменные подписи/надписи (voice: уверенный, космический, без канцелярита)
- Лого-слово: **MAXGRAPH** + подпись `CONTEXT MEMORY` (9px, letter-spacing 4px, --faint).
- Статусы: `● LIVE` (мигающая mint-точка), `SYNCED`, `30-DAY TRIAL`, `LICENSED`.
- Пустые состояния: «Здесь зажгутся твои первые звёзды» вместо «Нет данных».

## 4. Компоненты

### 4.1 HUD-панель (главный контейнер контента)
```css
.hud{
  background:var(--panel); border:1px solid var(--line);
  border-radius:var(--r-lg); backdrop-filter:var(--blur);
  position:relative; padding:22px;
}
/* уголки-кронштейны (реф B) — через ::before/::after на верхних углах,
   14px штрихи 2px цвета var(--cy), opacity .7. На мелких карточках не ставить. */
```
Hover (кликабельные): `border-color:var(--line-hi); box-shadow:var(--glow-cy); transform:translateY(-2px); transition: var(--t-fast) var(--ease)`.

### 4.2 Кнопки
- **Primary**: `linear-gradient(90deg,var(--cy),var(--vi))`, текст #04121A, weight 700, radius 12px, glow-cy тень; hover — поднять яркость (filter:brightness(1.12)).
- **Neon-ghost**: прозрачный фон, `border:1px solid var(--line-hi)`, текст --cy, hover → `background:rgba(70,240,255,.08); box-shadow:var(--glow-cy)`.
- **Danger-ghost**: то же с --rd.

### 4.3 Чипы/пилюли статуса
`border-radius:999px; padding:4px 12px; font-size:11.5px; border:1px solid`, раскраска по смыслу: активен/оплачен → mint, триал → amber, ошибка/просрочен → red, инфо → cyan.

### 4.4 Инпуты и код-блоки
- Инпут: `background:#0A0F1E; border:1px solid var(--line); radius 12px; padding 13px 16px`, focus → `border-color:var(--cy); box-shadow:0 0 0 3px rgba(70,240,255,.12)`.
- Код/ключ-блок: `--bg-2` фон, mono 12.5px, рамка --line, кнопка «копировать» в углу → после клика `✓` mint на 1.2s.

### 4.5 Чарты (ТОЛЬКО inline SVG/Canvas, БЕЗ внешних библиотек — офлайн-требование)
- **Барчарт**: скруглённые верхушки (rx=4), акцентный бар cyan/mint, остальные rgba(136,144,181,.25); hover — подсветка + тултип.
- **Линия**: stroke 2.5px cyan с `filter:drop-shadow(0 0 6px rgba(70,240,255,.6))`, под линией — градиентная заливка cyan→transparent 12%.
- **Донат**: толщина кольца 18–22%, сегменты --cy/--mi/--mg/--am, центр — KPI-число.
- **Спарклайн/стрим** (реф B): тонкая линия 1.5px, цвет по каналу.
- Всегда: легенда, значения при наведении, цвета дублируются формой/позицией (a11y).

### 4.6 Сфера-сеть (фирменный мотив, реф A)
Canvas или SVG: 24–60 узлов на сферической проекции, дуги-Безье между ближайшими, цвета --cy/--vi/--mg, `globalCompositeOperation:'lighter'`, узлы с радиальным halo. Медленное вращение (≥40s/оборот) или статика. Обязателен на лендинге (герой); в кабинете покупателя — маленькая (140–200px) как «пульс памяти»; на служебных панелях — НЕТ (там дисциплина).

### 4.7 Парящее окно-карточка (реф A)
Стекло + traffic-lights (3 круга #FF5F57/#FEBC2E/#28C840 слева сверху), внутри — «строки кода» как скруглённые бары разной ширины/цвета. Лёгкий float (translateY ±6px, 6–9s, staggered).

## 5. Сетки страниц

- **Лендинг**: max-width 1180px; герой (заголовок+сфера+CTA) → лента фич (3 карточки) → «как работает» (3 шага с HUD-нумерацией 01/02/03) → демо-окна → прайсинг (2 тарифа, Pro подсвечен glow) → FAQ (details/summary) → футер.
- **Кабинет покупателя**: max-width 1080px; шапка (лого, статус-пилюля, «пульс памяти» мини-сфера) → сетка 2 колонки (подписка / ключи) → **мастер привязки локального сервера (3 шага)** → конфиги MCP → покупка/лицензия.
- **Админка** (реф C): левый сайдбар 232px (--bg-2, иконки=inline SVG, активный пункт — mint-подсветка + вертикальная полоса) → топбар (заголовок, LIVE-чип) → ряд KPI-карточек (4) → ряд чартов (донат + бары + линия) → таблица покупок/кодов (sticky header, zebra rgba(255,255,255,.02), монo-коды) → лента событий.

## 6. Жёсткие правила (contract для всех страниц)

1. **Один файл = одна страница.** Весь CSS/JS инлайн. **Ноль внешних URL** (ни CDN, ни шрифтов, ни картинок) — self-hosted офлайн-продукт.
2. Иконки — только inline SVG (stroke 1.5–2, round caps), размер 16–20px. **Никаких emoji в UI** (в текстах маркетинга — допустимо умеренно).
3. Весь текст с сервера вставлять через `textContent` (никакого innerHTML с пользовательскими данными) — XSS.
4. Контраст: текст/фон ≥ 4.5:1; неоновый текст только для заголовков/меток ≥12px.
5. Фокус виден: `outline:2px solid var(--cy); outline-offset:2px` на интерактиве.
6. Кликабельное ≥ 44×44px; transition 150–280ms var(--ease); уважать reduced-motion. **Исключение:** press-feedback `:active{transform:scale(.97)}` — 100ms ease-out (отклик на pointer-down должен быть мгновенным, apple-design §1; при reduced-motion отключается). A11y-pack (`:active` + media `prefers-reduced-transparency`/`prefers-contrast`) копируется во все страницы **байт-в-байт** — блоки идентичны, меняются только селекторы под реальные кликабельные классы страницы.
7. Русский — основной язык; лендинг — RU+EN через `data-i18n` + localStorage `mg_lang` (как в текущем landing.html).
8. Адаптив: брейкпоинты 1080/860/640; на 640px сайдбар панелей → верхняя полоса, сетки → 1 колонка.
9. Палитра только из токенов выше — сырой hex вне `:root` запрещён (искл. traffic-lights).
