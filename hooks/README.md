# Maxgraph capture hooks — автоматический захват сессий

`maxgraph_hook.py` — универсальный хук (чистый stdlib, Python 3.10+), который
превращает события хоста агента в память MaxGraph:

```
хук хоста (stdin JSON) → нормализация → локальный spool ~/.maxgraph/spool.jsonl
→ POST батчами по 100 на $MG_SERVER/api/ingest (Bearer $MG_TOKEN, таймаут 3с)
```

- **Fail-open**: сеть/сервер недоступны → события молча остаются в spool и
  доставятся при следующем запуске. Скрипт **всегда** завершается кодом 0 —
  хук никогда не ломает и не блокирует хоста.
- **Идемпотентность**: content-hash (SHA256 `hook+project+ts+data`) — дедуп
  внутри spool при отправке + последние 1000 хэшей на сервере. Повторная
  доставка не создаёт дублей.
- **Проект**: определяется каскадом `git remote → git root → имя cwd`
  (kebab-slug); сервер принимает готовый slug. С git remote (v0.50.0) проект —
  стабильный тег `repo-<имя>-<хэш remote>`: один и тот же на любой машине и в
  любом агенте, а старые проекты подхватываются автоматически (алиас на сервере,
  ничего переносить не нужно).
- **Хост**: флаг `--host <имя>` (или env `MG_HOST`) переводит имена событий
  хоста в канонические (Claude Code — база).
- **Конфиг**: `MG_SERVER`/`MG_TOKEN` из env или из `~/.maxgraph/hooks.env`
  (файл пишет установщик — в конфиги хостов токен копировать не нужно).
  Переопределения: `MG_SPOOL`, `MG_HOOKS_ENV`.
- **Обратное направление (v0.49.0)**: помимо захвата, хук подмешивает память в
  контекст агента — выжимку проекта на старте сессии и подходящие факты по тексту
  промпта (маркер `▣`, источник — «из maxgraph»), а read-only инструменты памяти
  (поиск/просмотр) разрешает без лишних подтверждений. Записи всегда спрашивают
  пользователя. Выключатели: `MG_SESSION_INJECT=0`, `MG_RECALL=0`,
  `MG_PREAPPROVE=0`.

## Установка и рецепты per host

Установщик (install.sh / install.ps1) кладёт хук и `hooks.env` в `~/.maxgraph/`
сам. Регистрацию в конфиге хоста делает агент — **рецепты под каждый хост
(Claude Code, DSH, Cursor, Codex, Kimi Code, Antigravity, Gemini CLI,
Windsurf/Devin), удаление и проверка: [../docs/HOOKS.md](../docs/HOOKS.md)**.
