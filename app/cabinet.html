Привязка локального сервера self-hosted

Твой сервер — твои данные: память живёт на твоей машине, облако хранит только лицензию.

01

Запусти сервер 2 минуты

Нужен только Docker. Клонируй репозиторий и подними контейнер:

git clone https://github.com/RuMemory/maxgraph
cd maxgraph
cp .env.example .env
docker compose up -d --build
02

Активируй лицензию доступно после оплаты

Открой http://localhost:8787/app на своём компьютере и введи license key. Локальный сервер сам свяжется с магазином и подтвердит ключ — онлайн-валидация проходит один раз, дальше всё работает офлайн.

03

Смотри память вживую

Оставь вкладку открытой и наблюдай, как агент зажигает новые звёзды в твоём графе.

Открыть дашборд http://localhost:8787/app Живой граф памяти, обновляется каждые 8 с. Таймлайн вкладка в дашборде Все мутации графа: что, когда и кем записано. Экспорт кнопка Export в дашборде Полный бэкап памяти одним JSON-файлом.
